# Simple E-Commerce Store 🛒

A team project where I served as Project Lead, managing 
the entire workflow using Jira's Kanban template.

## What is Kanban?
Kanban is an Agile project management method that visualizes 
work using a board with columns representing stages:
- 📋 TO DO — tasks planned but not started
- ⚙️ IN PROGRESS — tasks currently being worked on
- ✅ DONE — completed tasks

## How I Used Kanban
- Created 35 user stories and subtasks on the Jira Kanban board
- Assigned each task to team members based on their skills
- Set due dates and priority levels for each task
- Tracked progress by monitoring cards moving across columns
- Used Jira Summary dashboard to monitor overall project health

## Project Modules
